# 🔄 Labyrinth: Find an outlet Maze Game

**🎮[PLAY IN BROWSER](https://qa-gamedev.github.io/unity-gravitymaze-game/)**

## 📖 О проекте
Мобильная игра-головоломка, построенная на механике изменения гравитации. Изначально проект был успешно опубликован в Google Play. 

Игрок должен провести объект к выходу из лабиринта. Весь пользовательский интерфейс для игры я проектировал и отрисовывал самостоятельно.

> **Примечание:** Данная WebGL-версия является архивным (Legacy) билдом для портфолио. Рекламные SDK вырезаны, а некоторые утерянные со временем иконки интерфейса заменены на функциональные заглушки.

## 🕹️ Управление
Оригинальное управление спроектировано под сенсорные экраны:
* **Изменение гравитации:** Свайп (проведение пальцем/курсором с зажатой ЛКМ) по экрану в нужную сторону — Вверх, Вниз, Влево или Вправо. Объект будет падать в заданном направлении до упора в стену.

## ⚙️ Особенности и механики
* **Процедурная генерация:** В игре нет заранее созданных уровней. Лабиринты генерируются бесконечно с помощью алгоритма, при этом каждые несколько уровней размер поля и сложность лабиринта динамически увеличиваются.
* **Система подсказок:** Если игрок застрял, он может активировать подсказку — алгоритм поиска пути проложит светящуюся линию от текущего положения объекта прямо к выходу.
* **Кастомизация:** За собранные на уровнях кристаллы игрок может покупать в магазине разнообразные косметические скины (от планет и виниловых пластинок до спортивных мячей). 
* **Архитектура монетизации:** В проекте реализована полноценная структура для In-App Purchases (внутриигровых покупок). Магазин включает в себя витрину с премиум-скинами и наборами валюты за реальные деньги. *(В текущей сборке оплата отключена)*.
